# Sports Streaming Pipeline

Лабораторна робота №3 з дисципліни «Професійний Python».
Присвячена ітераторам, генераторам, принципу `lazy evaluation`, модулю `itertools` та потоковій обробці великих наборів даних (на прикладі обліку спортивних результатів).

## Структура проєкту
- `src/sports_streaming/` — вихідний код модуля конвеєра.
- `data/` — папка для зберігання вхідних CSV-файлів.
- `report/` — звіт з лабораторної роботи.

## Запуск
```bash
python -m sports_streaming.main
